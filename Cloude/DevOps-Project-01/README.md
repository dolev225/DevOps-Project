An automated infrastructure-as-code solution for provisioning and configuring Amazon EC2 instances on AWS with proper networking, security groups, and automated user-data initialization scripts.

---

## 📌 Architecture Overview

This project automates the deployment lifecycle of an EC2 virtual machine, isolating network traffic with dedicated Security Groups and running boot-time automation scripts.
